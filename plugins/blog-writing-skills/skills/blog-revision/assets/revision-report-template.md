# 推敲レポート出力テンプレート

blog-revision スキルが推敲モードで出力する形式。最後のセクションは対象がファイルか貼り付け本文かで切り替える(SKILL.md の Step 4 に従う)。

```md
## 推敲レポート

### 判定
- 論調: 硬めの論調 / ふわっとした論調
- 適用軸: アテンションライティング / 作文技術 / 両方

### アテンションライティング軸
- 冒頭診断: (所見)
- 1 文長: (60 字超の文の指摘)
- 離脱ポイント: (段落の継ぎ目で引っ掛かりが無い箇所)
- 無駄な装飾: (前置き・自己言及・冗長表現)

### 作文技術軸
- 修飾語の順序: (違反箇所とルール名)
- 読点: (打刻の過不足)
- 入れ子構造: (主語と述語が遠い箇所)
- 表記: (漢字・ひらがな・家畜語の指摘)

### 変更点  ← 対象がファイルのとき
- 適用先: (書き換えたファイルパス)
- (変更した箇所を「元 → 直した後」で列挙。全文は書かない)

### 書き直し  ← 対象が貼り付け本文でファイルが存在しないとき
(全文。元の論旨・固有名詞・主張は変えない)
```

## 出力時のルール

1. 対象がファイルのときは書き直しをそのファイルへ直接適用し、レポートには「変更点」だけを書く。書き直し全文はチャットに出力しない。
2. 「書き直し」セクションに全文を置くのは、対象が貼り付け本文でファイルが存在しないときに限る。
3. ユーザーが「全文だけ」「差分だけ」「指摘だけ」と指示した場合はそれに従う。ファイル対象でも「全文をチャットに出して」と明示されたときは従う。
4. 強調表現の `**` は出力しない。
5. 各軸のセクションで該当が無い項目は省略せず「該当なし」と書く。
6. 「適用軸」がアテンションライティングのみの場合は作文技術軸のセクションを省略してよい。逆も同様。
