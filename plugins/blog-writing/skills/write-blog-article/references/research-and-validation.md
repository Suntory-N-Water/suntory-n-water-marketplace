# 調査と検証の方針

## 一次情報の調べ方

仕様書、公式ドキュメント、公式リポジトリ、リリースノート、Issue や Pull Request を優先します。検索結果の要約ではなく、元の公式資料を確認します。

判明した事実や制約を整理して利用者に説明します。根拠が確認できなかった場合は、根拠未確認であることを明記します。

## 検証が必須となる型

型 1（変更への追随）、型 2（手を動かす解説）、型 3（調査と比較）では実行による検証が必須です。型 4（意見と経験）では任意です。

環境が用意できず検証できない主張は未検証であることを明記し、記事を下書きの状態にとどめます。確かめた結果として記述できるのは、実際に動かして確認できた事実のみです。

## 作業場所

作業用の検証ディレクトリ（examples/<slug>/ など）に検証用の構成を作成します。この作業ディレクトリは除外設定（.gitignore など）に加え、Git の追跡対象外とします。

追跡対象外とする理由は、記事更新時には対象のバージョンが変わるため再作成が必要になる点と、依存関係の自動更新ツールや CI の不要な対象になるのを防ぐためです。

保存すべき対象は構成そのものではなく検証記録です。検証前に検証記録（verification.md など）を作成し、主張、確認手順、成功の判定基準を記載します。検証後に日付、環境、条件、確認した結果、検証できなかった範囲を追記します。実行ログ等も同ディレクトリに保存し、認証情報は記録しません。

## 検証の進め方

コードを書く前に、主張と確認方法を検証記録に書き出します。書き手が確認した条件と、レビュー側が検証した条件は分けて記録します。条件が異なる結果を比較する場合は違いを明記し、相手の検証結果を不当に否定しないようにします。

| 主張の種類 | 確認する方法 |
|---|---|
| ある値を返す | 実行出力、テストのアサーション |
| 失敗が発生する | 正確なエラーメッセージと発生条件の確認 |
| 代替動作が働く | 未対応状態を再現した上での動作確認 |
| 選択肢 A と B の差異 | 同一入力を与えた際の出力の比較 |
| 処理時間が変わる | 同一条件における複数回の実行時間測定 |

検証は、主張を支えるために必要な最小限の範囲で行います。

検証用プロジェクトの作成基準:
- 対象の技術そのものを動かす
- 画面や装飾は、挙動を確認できる最小限にとどめる
- 依存関係、import、設定ファイル、環境変数名を明記する
- 認証情報にはダミーまたは一時的なテスト用の値を用いる
- 記事に掲載するコードは、検証したコードと一致させる

## 記録する項目

検証対象に応じた記録項目を設定します。以下は主要な項目の例です。

| 対象 | 記録する項目 |
|---|---|
| 共通 | 検証日付、成功の判定基準、実際に確認した結果、検証できなかった範囲 |
| ローカル環境 | OS、ランタイムおよびパッケージのバージョン、実行コマンド |
| CI 環境 | 設定ファイル、実行 URL または実行 ID、実行日時、実行環境の種類、所要時間、関連ログ |
| クラウド実行環境 | デプロイ時のバージョン識別子、実行環境の設定 |

## 手元で完結しない対象の検証

CI 環境など手元だけで完結しない対象は、一時的な検証用リポジトリを作成して検証します。

手順は次のとおりです。

1. 作業ディレクトリを用意し、設定ファイルと検証記録を準備します。
2. 実行前に利用者へ確認と承認を求めます。
3. 一時的なプライベートリポジトリを作成します。
4. 設定を反映して実行します。
5. 実行ログを取得します。
6. 設定ファイル、実行識別子、実行日時、所要時間、ログの該当部分を検証記録に保存します。
7. 検証結果にかかわらず、作成した一時リポジトリを削除します。
8. 削除が完了したことを確認します。削除に失敗した場合は理由と場所を報告します。

リポジトリの作成と削除は影響が大きいため、事前に必ず承認を得てから実施します。

## 記事本文と検証用ディレクトリの関係

検証用ディレクトリは作業場所であり、読者には渡りません。そのため記事本文には、読者が自身の環境だけで再現できる情報のみを記述します。ローカルパス、検証用ディレクトリ名、検証用リポジトリの場所は記事本文には含めません。

検証環境の詳細一覧、確かめられなかったことの一覧、検証の試行錯誤、手元の環境固有のトラブルは、読者向けの情報ではないため記事本文には含めず、検証記録側に残します。

検証で得られた事実そのもの（確かめた条件と結果）は記事本文に明確に記述します。

- 改善前: 「検証用サンプルでは 40 秒でした」
- 改善後: 「キャッシュを無効にした状態で実行したところ、40 秒でした」
