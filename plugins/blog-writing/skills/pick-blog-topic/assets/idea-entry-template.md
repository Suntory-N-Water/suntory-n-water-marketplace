`ideas` コレクションの `body` に書く Markdown の形式。`title`、`question`、`stage` は別のフィールドに入れるため、ここには書かない。該当する内容がない見出しは省く。

```markdown
## 参照資料

- URL:
- 出典の種類: （記事 / 公式資料 / 作業記録 / 会話 / その他）
- 要点:

## 会話で整理した内容

- 最初に出た問い:
- 会話で整理された説明や比較:
- 説明の出所:
- 確認状況:
- 利用者が述べた経験や見方:

## 具体例・コード・数値

- 内容:
- 出所: （利用者の説明 / 会話中の AI の説明例 / 公式資料 / 実験結果 / その他）
- 確認状況: （本人が述べた内容 / 説明用の例 / 資料で確認済み / 実行済み / 未確認）

## 足りないもの

記事にするために必要な資料、実例、測定値、利用者の経験などを書く。

## 確かめること

次に調べることや試すことを、会話や資料で出た範囲に沿って書く。
```
